# Suresh Raj Annavarapu — Portfolio

A responsive one-page portfolio website for Suresh Raj Annavarapu, styled around project management, construction, and QA/QC.

## Files
- `index.html` — all portfolio content
- `style.css` — complete responsive styling
- `script.js` — mobile navigation + scroll reveal animations
- `assets/` — optional folder for future photos, resume PDF, or project images

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a GitHub repository. For a personal homepage, name it exactly `<username>.github.io`.
2. Upload all files in this folder to the repository root.
3. Commit and push.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Visit `https://<username>.github.io/`.

If the repository is not named `<username>.github.io`, the URL will normally be `https://<username>.github.io/<repository-name>/`.

## Customize
Search `index.html` for the text you want to change. Colors are defined near the top of `style.css` in `:root`.
